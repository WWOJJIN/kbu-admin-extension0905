# Google Stitch 프롬프트 — 협조문 탭

아래 내용을 그대로 복사해서 Stitch에 붙여넣으시면 돼요. 스크린샷(이전에 보내드린 실제 화면 캡처나 5가지 레이아웃 시안 이미지)을 같이 첨부하시면 Stitch가 지금 구조를 훨씬 정확하게 참고해서 더 나은 결과를 줄 거예요.

---

```
대학교 행정팀이 쓰는 크롬 확장 프로그램(데스크톱 웹앱)의 "협조문" 화면을 디자인해줘.
왼쪽에 고정 사이드바 내비게이션이 있고, 이 화면은 그 오른쪽 메인 콘텐츠 영역이야.

[화면 목적]
여러 부서에서 온 공문(협조문)을 목록으로 확인하고, AI가 요약해준 내용과 마감일을 빠르게 훑어보고,
캘린더에서 이번 달 마감 흐름을 보고, 조치가 필요한 항목을 처리하는 화면.

[레이아웃 구조]

1. 상단 헤더
   - 페이지 제목 "협조문수신함" (굵은 글씨)
   - 제목 바로 아래에 검색창("제목, 부서, 내용으로 검색" placeholder)과 부서 필터 드롭다운("전체")을 나란히 배치

2. 좌측 영역 (전체 폭의 약 60%) — 협조문 카드 2열 그리드
   각 카드는 위/아래 두 구역으로 나뉨:
   - 위쪽(흰 배경): 발신부서·기안자 텍스트("혁신지원사업단 · 김양진") + 오른쪽에 작은 "NEW" 배지,
     제목(2줄까지), 수신부서와 날짜(작은 아이콘 + 텍스트, "수신: OOO · 2026-09-01")
   - 아래쪽(옅은 파란색 배경 박스, 카드 안쪽에 둥근 모서리로 살짝 띄워진 느낌): "✨ AI Summary" 라벨,
     그 아래 "기한 2026-09-30" / "조치 OOO" 한 줄씩, 요약 문단(2~3문장)
   - 카드 하단 오른쪽엔 상태 배지 하나 ("제출 필요" 주황, "완료" 초록, "캘린더 등록됨" 파랑 중 하나)
   - 카드 그리드 아래에 페이지네이션(숫자 버튼 + 이전/다음 화살표)

3. 우측 영역 (전체 폭의 약 40%) — 세로로 두 개 카드
   - 위: 미니 캘린더. 상단에 "← 2026년 9월 →" 월 이동, 7열 요일 그리드, 협조문 마감일이 있는 날짜엔
     작은 점(dot) 표시, 하단에 "협조문 마감" 범례
   - 아래: "처리해야 할 일" 카드. 자동으로 조치가 필요하다고 판단된 항목 리스트 —
     각 항목은 제목, 마감일(주황 텍스트), 선택적으로 메모(회색 박스 텍스트), 오른쪽에 메모 추가 버튼(+)과
     완료 처리 버튼(밑줄 텍스트 스타일, 눈에 튀지 않게). 완료된 항목은 흐리게 처리되고 제목에 취소선,
     "완료됨" 초록 라벨이 붙지만 목록에서 사라지지 않고 계속 보임

[컬러 팔레트]
- 사이드바/제목 텍스트: 네이비 #1A1B2E
- 포인트 컬러(버튼, 활성 상태, 링크): 블루 #4F6EF7 (진한 버전 #3D57E8)
- 배경(페이지 전체): 아주 옅은 블루-화이트 #F5F7FF
- 카드 배경: 흰색, 테두리 #E4E7F2
- 보조 텍스트: 그레이 #6B7280
- 경고/마감 강조: 앰버 #D9822B (배경 #FDF3E7)
- 완료 상태: 그린 #1E9E6E (배경 #EAF7F1)

[타이포그래피]
한글 산세리프 (Pretendard 계열, 없으면 시스템 기본 산세리프). 제목은 굵게, 본문은 작고
정보 밀도가 높게(공공기관 행정 업무 도구답게 여백보다 정보량을 우선). 숫자/날짜는 깔끔하게 정렬.

[톤 & 무드]
깔끔하고 신뢰감 있는 기업용 SaaS 대시보드 느낌. 카드 기반 레이아웃, 은은한 그림자(과하지 않게),
둥근 모서리(12~16px 정도). 화려하거나 트렌디한 느낌보다는 정돈되고 실무적인 행정 도구의 인상.

[요청]
위 구조와 정보량은 그대로 유지하면서, 지금보다 더 현대적이고 시각적으로 정돈된 버전으로
리디자인해줘. 카드 안의 정보 위계(제목 vs AI 요약 vs 메타 정보)가 한눈에 더 잘 들어오게 해줘.
```

---

**참고**: 마지막 `[요청]` 부분은 원하는 방향에 맞게 바꿔서 쓰시면 돼요. 예를 들어

- "더 여백을 넉넉하게, 미니멀하게 바꿔줘"
- "카드에 색상 포인트를 부서별로 다르게 줘서 구분이 잘 되게 해줘"
- "모바일에서도 잘 보이는 반응형으로 제안해줘"

같은 식으로 마지막 문단만 교체하면 같은 구조 설명을 재사용할 수 있어요.
